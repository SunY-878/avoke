# Sky Island · 天际岛

一个原生 macOS 灵动岛，用一个安静的黑色岛体连接此刻的音乐、复制的灵感和系统状态。
SwiftUI + AppKit，无 Electron，无第三方 Swift 包依赖。支持 macOS 14 及以上、Apple Silicon / Intel（在对应机器上构建）。

## 直接使用

双击当前目录的 **`dist/Sky Island.app`**，或双击 **`启动天际岛.command`**。
应用常驻菜单栏，不显示 Dock 图标。

- 鼠标移到屏幕顶部中央：岛体平滑展开，移开后自动收起。
- 正在播放：显示封面、歌曲、歌手、专辑和动态声波；展开后可播放 / 暂停、切歌、拖动进度。
- 剪贴板：记录启动后的文本、链接、图片、文件；点击记录重新复制，再在目标应用按 `⌘V`。
- 系统：展开后点击“系统”页签，或从菜单栏 → 系统状态进入，查看 CPU / 内存占用、最近一分钟趋势、实时上传 / 下载速率、连接状态及磁盘可用空间。向下滚动查看压缩 / 交换内存、热状态及运行时间；可直接打开活动监视器。
- 唤醒：选择“显示器常亮”或“后台运行”，设置时长后启动。后台模式允许显示器按系统设置关闭，并支持一键立即关屏。开启后收起的岛体会显示咖啡杯标记；没有音乐时显示模式与剩余时间。
- 行内按钮或右键菜单：预览、置顶、删除；支持内容 / 来源搜索和分类过滤。
- `⌥ Space`：呼出并固定 / 收起；`Esc`：收起；图钉：保持展开。
- `F13`：直接切换防休眠。按一次按当前选择的模式和时长开启，再按一次结束，恢复正常自动休眠；保持界面原有的展开、收起和固定状态。可将 ANTICATER 等可编程按钮的按下动作映射为 `F13`。
- 菜单栏 → 设置：点缀色、大小、悬停延迟、顶部距离、显示器、历史容量、暂停记录、登录时启动。
- 菜单栏 → 体验演示：预览音乐和剪贴板视觉效果。演示不会改动系统剪贴板，退出后恢复真实历史。

刘海屏默认贴合硬件刘海；普通屏幕默认采用顶部悬浮胶囊。可在设置中调整顶部距离。
空闲时保留一个小入口，播放时自动显示当前曲目。窗口跟随所选显示器，支持不同桌面及全屏空间。
网络断开或恢复时显示短暂提示，点击可进入系统页查看状态。

## 防休眠

展开灵动岛 → **唤醒**，或从菜单栏 → **防休眠**进入。应用启动时不会自动开启防休眠。

Sky Island 运行时，按 `F13` 可直接开启防休眠，再按一次即可结束，操作不会展开或固定界面。默认模式为“后台运行”、时长为 1 小时；在“唤醒”页选择其他模式和时长后，下一次开启沿用当前选择。按钮配置方法：在 ANTICATER 配套软件中选择旋钮按下动作，设为键盘 `F13`，再点击“保存设置”。也可以使用页面的“结束”或菜单栏的“结束防休眠”。

| 模式 | 行为 | 对应命令参数 |
| --- | --- | --- |
| 显示器常亮 | 阻止显示器、系统和磁盘自动休眠 | `caffeinate -dim` |
| 后台运行 | 显示器按设置正常关闭；阻止系统和磁盘自动休眠，供后台网络 / 磁盘任务继续运行 | `caffeinate -im` |

支持 15 分钟、30 分钟、1 小时、2 小时及不限时；“应用设置”会按新模式和时长重新开始。结束、到期或退出应用时释放请求。后台模式的“立即关屏”只关闭显示器，防休眠继续生效；移动鼠标可唤醒屏幕。

功能通过 IOKit 创建与 `caffeinate` 对应的电源请求，包含系统和磁盘防休眠，不修改系统电源偏好。定时请求同时交给 macOS 处理超时，避免应用无响应时无限保持唤醒。
这些请求阻止的是自动空闲休眠，**不绕过合盖、手动睡眠、低电量等系统睡眠行为**，与 [Apple 电源请求说明](https://developer.apple.com/documentation/iokit/kiopmassertiontypepreventuseridlesystemsleep) 一致。
保持本机唤醒不能阻止外部网络故障、服务器超时、拔盘或设备自身的休眠策略，也不改变其他应用自身的任务运行策略。

## 构建与开发

需要 Swift 6（Xcode 16 或较新的 Apple Command Line Tools）。

```bash
./Scripts/build.sh              # 编译、构建媒体组件、生成图标、签名 .app
./Scripts/run.sh                # 构建并启动
./Scripts/run.sh --demo         # 构建并启动演示
swift test                     # 核心逻辑与隔离剪贴板集成测试
```

用 Xcode 打开 `Package.swift` 即可编辑项目。运行时请使用打包的 `.app`，以加载附带的媒体组件。
构建默认为本机架构。`CONFIGURATION=debug ./Scripts/build.sh` 可构建调试版本。

实际 SwiftUI / AppKit 界面可渲染成图片，输出在 `docs/previews/`：

```bash
"dist/Sky Island.app/Contents/MacOS/SkyIsland" --render-previews "$PWD/docs/previews"
"dist/Sky Island.app/Contents/MacOS/SkyIsland" --check-media  # 验证真实媒体流，不操作播放器
"dist/Sky Island.app/Contents/MacOS/SkyIsland" --check-system # 输出真实 CPU、内存、磁盘和网速数据
```

## 数据与权限

- 剪贴板不发送到网络。默认以本机 JSON 保存到 `~/Library/Application Support/SkyIsland/clipboard.json`，目录权限 `700`、文件权限 `600`，内容未加密。
- 关闭“重启后保留历史”会删除磁盘历史；内存历史保留到退出。清空历史会同时删除置顶项。
- 自动跳过标记为 Concealed / Transient / AutoGenerated 的内容，以及已识别的 1Password 标记。未标记的敏感文本无法可靠识别，可随时暂停记录。
- 图片历史用于预览与再次复制，最长边不超过 1600 像素；超大内容跳过，总历史数据限制约 24 MB，最多 20 个置顶项。
- 不需要辅助功能、屏幕录制或 AppleScript 自动化权限。使用系统粘贴板和媒体元数据。系统自身的权限设置可能影响粘贴板读取。
- 登录启动由 macOS ServiceManagement 管理，仅在设置中主动打开后注册。
- 系统状态通过原生 Mach / Foundation / Network 接口在后台读取，不启动 `top` 等外部采样进程，不需要额外权限。CPU / 内存 / 网速每秒更新，磁盘每 15 秒更新。最近 60 个趋势点仅存在内存中，不保存或上传。
- 网速统计当前启用的 `en*` 物理网络接口，包含局域网流量；排除回环与 VPN 虚拟接口以避免重复计数。单位为十进制 B/s、KB/s、MB/s。首次采样、接口重置或采样中断后重新建立基线。
- 连接状态来自 `NWPathMonitor` 的系统网络路径，不进行外部探测，不代表互联网或某个远端服务一定可达，也不读取 Wi-Fi 名称或上传流量明细。

CPU 使用率按采样间隔内所有逻辑核的忙碌时间计算，整机范围为 0–100%，首次采样显示占位值。
内存用量为应用驻留内存（扣除可清理部分）、系统固定内存和压缩内存之和，文件缓存不计入已用内存；交换内存单独显示。
这些分类与 [Apple 活动监视器的内存说明](https://support.apple.com/guide/activity-monitor/view-memory-usage-actmntr1004/mac) 对应。
磁盘指用户目录所在卷，可用容量包含 macOS 可清理的空间；热状态为系统报告的热负荷等级。

音乐使用 [MediaRemote Adapter](https://github.com/ungive/mediaremote-adapter) 接收系统 Now Playing 元数据。
Music、Spotify、网易云及浏览器等播放器，只有在向系统发布 Now Playing 信息时才能识别；不发布信息的播放器不支持。
MediaRemote 是私有框架，系统升级可能影响接入；连接故障会在界面显示，可通过设置重新连接。

当前 `.app` 已做本地 ad-hoc 签名，适合本机使用；分发给其他机器需自行使用 Developer ID 签名与公证。

## 文件结构

| 路径 | 内容 |
| --- | --- |
| `Sources/SkyIsland` | 原生窗口、交互、SwiftUI 界面、媒体 / 剪贴板 / 系统与网络采样 / 防休眠服务 |
| `Sources/IslandCore` | 媒体解析、历史策略、系统指标、网速计算及防休眠模式定义 |
| `Tests` | 核心逻辑及独立 NSPasteboard 集成测试，不触碰系统剪贴板 |
| `Vendor/MediaRemoteAdapter` | 固定版本 BSD 许可媒体组件源码 |
| `Scripts` | 一键构建、启动、原生应用图标生成 |

交互思路参考 [Sapphire](https://github.com/cshariq/Sapphire)，UI 与 Swift 应用代码为独立实现。
第三方来源及许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 已完成的验证

- 本机 macOS 26.5 / Swift 6.2 Release 构建及 app / framework 签名验证通过。
- 37 项自动化测试通过，覆盖原有媒体、悬停、剪贴板和系统采样，以及网速差分 / 接口重置、连接状态提示、防休眠模式 / 定时 / 切换失败回滚、真实电源请求创建与释放。测试不会执行立即关屏，也不会修改系统网络连接。
- 打包后的应用通过 `--check-media` 真实接收 QQ 音乐的曲目信息与封面；检查只读取信息，不改变播放器状态。
- 1.1 版通过 `--check-system` 验证了整机 CPU、物理内存、磁盘容量、热状态和运行时间的真实读取，采样无错误。
- 1.2 版通过打包应用验证了真实 Wi-Fi 连接状态和上传 / 下载速率，采样无错误；电源请求测试结束后检查 `pmset -g assertions`，未留下 Sky Island 请求。
- 原生界面预览位于 [docs/previews](docs/previews)，系统与防休眠页面包括普通屏幕、刘海屏、未开启、显示器常亮、后台运行等状态。预览使用演示数据，防休眠预览不会创建真实电源请求；正常运行使用真实采样和电源请求。
- 直接鼠标点击的自动化检查未执行：计算机操作工具拒绝访问新建的 Sky Island 应用，返回 “Computer Use was not approved to use Sky Island”。悬停逻辑通过状态机测试，布局通过真实 SwiftUI / AppKit 渲染检查。
